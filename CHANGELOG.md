# Changelog

Scilla is a fork of [mikan](https://github.com/Miroshka000/mikan), renamed as required by
the original project's additional license terms. The upstream project's changelog is kept
in [CHANGELOG.upstream.md](CHANGELOG.upstream.md).

Each release has a section in English and in Russian; the release workflow puts them in
the signed manifest, and the panel shows the one in its language.

## Unreleased

### en

- Renamed the project from mikan to Scilla: module, binaries, command-line tool, cookie,
  environment variables (`SCILLA_*`), node join keys, metrics, rule-set names and all
  user-visible strings.

- Проект переименован из mikan в Scilla: модуль, бинарники, CLI, cookie, переменные
